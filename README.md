# Catholic Knowledge

A visual, source-backed Catholic knowledge platform combining an encyclopedia, interactive knowledge graph, historical atlas, learning system, and grounded AI tutor.

> **Product principle:** Sources create facts. AI creates explanations.

## Vision

Catholic Knowledge helps people understand how Scripture, history, saints, places, doctrine, councils, writings, and ideas connect.

The experience should feel like a modern digital museum, encyclopedia, and interactive knowledge atlas — not a generic SaaS dashboard or a plain wiki.

## Initial MVP

The first vertical slice will focus on:

- Home / Discover
- Saint Entity Explorer — St. Augustine
- Interactive Knowledge Graph
- Source/provenance presentation
- EN / VI-ready content architecture

## Planned Stack

- Next.js + TypeScript
- Tailwind CSS
- React Flow / SVG / Mermaid for deterministic diagrams
- Local typed content first
- Cloudflare Pages / Workers / D1 later
- AI used for explanations and authoring assistance, not canonical facts

## Documentation

See `/docs` for product, design, architecture, ontology, source/licensing, and delivery documentation.

## Development Principle

All knowledge UI should be data-driven, factual content should support provenance, and visualizations should be reusable across saints, Scripture, councils, doctrine, history, and places.
